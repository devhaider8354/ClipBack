Third-party components
----------------------
ClipBack uses only components that ship with Microsoft Windows (Direct3D 11,
DXGI, Windows Graphics Capture, Media Foundation, WASAPI, Win32 / Common
Controls). Hardware encoders (NVIDIA NVENC, AMD AMF, Intel Quick Sync Video)
are accessed through the vendors' Media Foundation transforms installed by
the graphics driver.
