# ClipBack

[![Build](https://github.com/devhaider8354/ClipBack/actions/workflows/build.yml/badge.svg)](https://github.com/devhaider8354/ClipBack/actions/workflows/build.yml)

[English](README.md) | **العربية**

برنامج إعادة فورية (Instant Replay) لألعاب ويندوز. يحتفظ بآخر 30 أو 60 أو 120 ثانية من اللعب في الذاكرة، وعند الضغط على مفتاح الاختصار (افتراضياً **F10**) يحفظها كفيديو MP4 — نفس فكرة NVIDIA Instant Replay لكن يعمل مع كل كروت الشاشة (NVIDIA و AMD و Intel) وبدون أي برامج إضافية.

## المميزات

- **خفيف جداً**: برنامج C++ أصلي بملف واحد (1-2 ميغابايت)، بدون مكتبات خارجية.
- **بدون تأثير على أداء اللعبة**: الالتقاط والتحويل والترميز كلها على كرت الشاشة (NVENC / AMF / Quick Sync).
- **صفر كتابة على القرص** حتى تضغط حفظ؛ آخر 60 ثانية تحتاج حوالي 90 ميغابايت من الذاكرة فقط.
- **تسجيل صوت اللعبة** مع المايكروفون اختيارياً، والصوت متزامن مع الصورة.
- **تسجيل المباراة كاملة** بمفتاح واحد مباشرة على القرص.
- **آمن مع أنظمة مكافحة الغش**: يستخدم واجهات ويندوز الرسمية فقط، بدون حقن أو هوكات داخل اللعبة.
- **واجهة عربية وإنجليزية** مع دعم كامل للاتجاه من اليمين لليسار.
- أيقونة في شريط المهام، إشعارات، وتشغيل تلقائي مع ويندوز.

## التحميل

حمّل `ClipBack-Setup.exe` من صفحة [Releases](../../releases) (ويندوز 10 إصدار 1903 أو أحدث / ويندوز 11، 64 بت).
شغّل أي لعبة، والعب، واضغط **F10** — تُحفظ آخر 60 ثانية في مجلد `Videos\ClipBack`.

## الاستخدام

| العملية | الطريقة |
| --- | --- |
| حفظ آخر اللقطات | **F10** (قابل للتغيير من الإعدادات) |
| حفظ من النافذة | **Ctrl+S** |
| فتح مجلد الفيديوهات | **Ctrl+O** |
| خروج | **Ctrl+Q** (زر X يصغّر البرنامج لشريط المهام فقط) |

الإعدادات محفوظة في `%LOCALAPPDATA%\ClipBack\config.json`، وسجل الأخطاء في `%LOCALAPPDATA%\ClipBack\logs\clipback.log`.

## البناء من المصدر

يحتاج Visual Studio 2022 (مع C++ و Windows SDK 10.0.19041 أو أحدث) و CMake. التفاصيل الكاملة في [BUILD.md](BUILD.md).

<div dir="ltr">

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
